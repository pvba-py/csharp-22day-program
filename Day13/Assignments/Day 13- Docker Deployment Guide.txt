# PART A: One-Time Setup Commands

You only need these when starting from scratch or on a new machine/subscription.

***

## 1. Login to Azure

```powershell
az login
```

Check active subscription:

```powershell
az account show --output table
```

If needed, set subscription:

```powershell
az account set --subscription YOUR_SUBSCRIPTION_ID
```

***

## 2. Create Resource Group

```powershell
az group create --name RG-ORScheduling-India --location centralindia
```

***

## 3. Register Required Providers

```powershell
az provider register -n Microsoft.ContainerRegistry --wait
```

```powershell
az provider register -n Microsoft.App --wait
```

```powershell
az provider register -n Microsoft.OperationalInsights --wait
```

Validate:

```powershell
az provider show -n Microsoft.ContainerRegistry --query registrationState -o tsv
```

```powershell
az provider show -n Microsoft.App --query registrationState -o tsv
```

```powershell
az provider show -n Microsoft.OperationalInsights --query registrationState -o tsv
```

Expected:

```text
Registered
```

***

## 4. Create Azure Container Registry

ACR name must be:

```text
lowercase + numbers only
no underscore
no hyphen
globally unique
```

Command:

```powershell
az acr create --resource-group RG-ORScheduling-India --name acrormadithya007 --sku Basic --admin-enabled true
```

Validate:

```powershell
az acr show --name acrormadithya007 --query loginServer -o tsv
```

Expected:

```text
acrormadithya007.azurecr.io
```

***

## 5. Install Container Apps Extension

```powershell
az extension add --name containerapp --upgrade
```

If it says preview extension, that is okay.

***

## 6. Create Container Apps Environment

Low-cost version without Log Analytics:

```powershell
az containerapp env create --name or-scheduling-env --resource-group RG-ORScheduling-India --location centralindia --logs-destination none
```

If `--logs-destination none` fails, use:

```powershell
az containerapp env create --name or-scheduling-env --resource-group RG-ORScheduling-India --location centralindia
```

# PART D: First-Time Deployment to Azure Container Apps

Use this only if the Container App does **not** already exist.

***

## 15. Create Container App

For `v1`:

```powershell
az containerapp create --name or-scheduling-api --resource-group RG-ORScheduling-India --environment or-scheduling-env --image acrormadithya007.azurecr.io/or-scheduling-api:v1 --registry-server acrormadithya007.azurecr.io --registry-username $(az acr credential show --name acrormadithya007 --query username -o tsv) --registry-password $(az acr credential show --name acrormadithya007 --query passwords[0].value -o tsv) --target-port 8080 --ingress external --cpu 0.25 --memory 0.5Gi --min-replicas 0 --max-replicas 1
```

Low-cost settings:

```text
--min-replicas 0
--max-replicas 1
--cpu 0.25
--memory 0.5Gi
```

# Is This CI/CD?

No — this is **manual deployment**.

CI/CD would be:

```text
Push code to GitHub
↓
GitHub Actions automatically builds Docker image
↓
Pushes image to ACR
↓
Updates Azure Container App
```

Your current manual flow is perfect for learning Docker and Azure deployment fundamentals. Next step later: we can automate this using **GitHub Actions CI/CD**.
